# Промежуточный отчёт: «ИИ-ревизор ОСИ»

**Автор:** индивидуальный проект. **Курс:** AI Capstone.

## 1. Тема и актуальность
Объединения собственников имущества (ОСИ) в Казахстане ежемесячно публикуют отчёты о
доходах и расходах. Проверять их вручную долго: нужно сверить суммы, остатки между
месяцами, сопоставить расходы с документами. Приложение автоматизирует первичную проверку
и подсказывает жителям и ревизионной комиссии, какие документы запросить.

## 2. Постановка задачи
Вход: отчёты ОСИ (PDF, сканы, фото), чеки и другие документы.
Выход: список замечаний с пояснениями, уточняющие вопросы («загрузите чек по расходу …»),
итоговый отчёт с оценкой риска.

## 3. Интеграция CV + NLP + ML
* **CV:** выпрямление скана, поиск линий таблицы (OpenCV), OCR (EasyOCR).
* **NLP:** нечёткое определение роли строк, разбор названий контрагентов (ТОО/ИП/АО),
  классификация назначения расхода.
* **ML:** классификатор категорий (TF-IDF + LogReg/SVM/NB), сравнение моделей.
* **Логика ревизора:** иерархические суммы, баланс остатков между месяцами, план/факт.

## 4. Данные
Реальные: 3 месячных скана, годовой отчёт, смета одного ОСИ (для разработки и проверки на
«отсутствие ложных срабатываний»). Синтетические: сгенерированные серии отчётов по реальной
форме с внедрёнными нарушениями и известной разметкой. Размеченные строки: 58 реальных
назначений расходов (20 категорий).

## 5. Фреймворки
Python, OpenCV, EasyOCR, pdfplumber, scikit-learn, RapidFuzz, Streamlit, Docker, Hugging Face Spaces.

## 6. План
1. Парсер отчётов (готово). 2. Проверки и оценка на синтетике (готово). 3. Классификатор и
сравнение моделей (готово). 4. Вопросы + итоговый отчёт + Streamlit (готово).
5. Развёртывание на Hugging Face (в процессе). 6. Расширения: парсер сметы, договоры.

## 7. Ожидаемые результаты и значимость
Сокращение времени первичной проверки, прозрачность расходов ОСИ; метрики — precision/recall
проверок на синтетике, macro-F1 классификатора, отсутствие ложных нарушений на реальных документах.
