# План презентации (10 мин + 5 мин вопросов)

1. **Проблема (1 мин).** Отчёты ОСИ длинные, проверка вручную; что обычно скрывается:
   несходящиеся суммы, повторные платежи, смена формы контрагента.
2. **Идея и демо-сценарий (1 мин).** Приветствие → история (по желанию) → загрузка →
   вопросы → итоговый отчёт.
3. **Данные (1 мин).** Реальные сканы + синтетика с внедрёнными нарушениями; почему так.
4. **Архитектура (2 мин).** Схема из README: CV → OCR → таблица → NLP/ML → проверки → вопросы.
5. **Живая демонстрация (3 мин).** Кнопка «демо-данные» → замечания → «добавить демо-чеки» →
   закрытые вопросы → скачать отчёт. Запасной вариант: скриншоты/запись.
6. **Результаты (1,5 мин).** Таблица проверок, сравнение моделей классификации, реальные документы:
   0 ложных нарушений по арифметике + найденные аномалии.
7. **Ограничения и дальше (0,5 мин).** Форма № 164, смета/договоры, OCR на плохих фото.

## Вероятные вопросы
* *Почему метрики на синтетике такие высокие?* Это верхняя оценка; поэтому добавлена проверка на реальных документах.
* *Почему не LLM?* Детерминированные проверки объяснимы и воспроизводимы; ML — там, где нужен смысл (категории).
* *Что с приватностью?* Файлы не сохраняются; история по желанию и удаляется.
* *Что сломается на другом ОСИ?* Другая форма отчёта; парсер рассчитан на приказ № 164.
